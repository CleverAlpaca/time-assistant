# 时光助手

玻璃拟态（Glassmorphism）风格的 Windows 桌面时间管理工具：番茄钟 · 闹钟提醒 · 待办 · 日历 · 专注统计。浅色基底 + 天蓝/淡紫/粉紫/薄荷四色光晕背景，高透明度白色玻璃卡片，天空蓝渐变主色，Windows 风格窗口控制按钮；支持浅色/深色/跟随系统。

## 功能

| 功能 | 说明 |
|---|---|
| 番茄钟 | 专注/短休/长休自动循环（25/5/15 分钟可配置），环形进度 + 周期圆点，可关联待办任务 |
| 倒计时 / 计时器 | 时长项可管理（点击使用 · 右键修改/删除、再点已选项直接修改）、「新增」自定义时长（精确到毫秒）与备注并存入时长项；三组计时器并行独立互不打断（全部毫秒级显示），侧栏多任务显示（新任务在上）、点击跳转，重置/停止才移除；计时器停止后自动计入统计 |
| 闹钟提醒 | 一次 / 每天 / 每周（多选星期），到点系统通知，支持贪睡 5 分钟；睡眠唤醒 60 秒内错过的补发 |
| 待办任务 | 优先级、截止日期，设置截止时间可自动生成到期提醒；完成自动解除提醒 |
| 日历日程 | 月视图：日程圆点、到期待办标记、每日专注时长热力背景；日程可设提前 0–30 分钟提醒；农历/节气/节日 + 法定节假日「休/班」角标 |
| 专注统计 | 今日/本周/本月时长与番茄数、近 7/30 天柱状图、连续专注天数、任务排行 |
| 体验细节 | Windows 风格窗控（右上角）、玻璃侧栏、浅/深/跟随系统主题、托盘常驻（悬停显示剩余时间）、置顶悬浮计时窗、开机自启 |

## 运行

```bash
npm install        # 首次
npm run icon       # 重新生成图标（一般无需）
npm start          # 启动
```

## 打包

```bash
npm run dist       # 产出 NSIS 安装包 + 便携版（dist/ 目录）
```

## 技术说明

- **架构**：Electron 39 + 原生 JS，零运行时依赖（仅 electron / electron-builder 开发依赖）
- **计时引擎在主进程**：切页、最小化到托盘不中断；托盘提示、悬浮窗、主窗口三处显示同源同步
- **数据**：本地 JSON（`%APPDATA%/time-assistant/`），主进程原子写入，渲染层经 contextBridge 安全桥访问
- **提醒**：系统通知 + 前台轻提示音（Web Audio 合成，无音频资源文件）；待办/日程的提醒以关联闹钟记录实现，随源条目增删自动同步
- **法定节假日**：静态表为人工核对的官方原文（2025/2026）；后续年份应用自动联网同步——数据源
  [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)（社区 CI 解析国务院通知，发布后数小时内更新），
  jsdelivr CDN 与 api.github.com 双通道互备，缓存于数据目录 `holidays-cache.json`；
  启动时预热当年与次年，日历翻到缺数据的年份按需拉取，未发布的年份记 24 小时负缓存（公布后自动生效），离线静默降级
- **图表**：手写 SVG，无图表库

src/preload.js             安全桥
src/renderer/index.html    主窗口布局
src/renderer/app.css       苹果风设计系统（深浅色）

src/renderer/js/*          各页面模块 + 数据封装 + 应用外壳
scripts/make-icon.mjs      纯 Node 生成应用图标
